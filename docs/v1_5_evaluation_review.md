# 추가 평가 지시문 검토

2026-10-28. 사용자 제공 「V1.5 추가 지시: 실제 강의 영상 기반 평가 및 V2 연계 검증」에 대한 검토다.
이 문서는 V2 구현 지시가 아니라 현재 V1.5 평가 목적과 범위를 검토한 기록이다.

## 판단

방향은 타당하다. 원래의 학습 없는 V1.5 범위와 양립한다. 특히 원본 RGB 보존,
픽셀 품질과 OCR/수식 의미 보존의 구분, 합성과 실제 결과의 분리,
추가 대형 모델 없이 가능한 평가부터 진행한다는 기준을 유지해야 한다.

## 실행 전에 명확히 할 사항

1. **표본 수**: 12~20장은 서로 다른 실제 원본 프레임 수로 센다.
   3장을 1080p/720p로 만든 것은 6개 조건이지 독립적인 실제 프레임 6장이 아니다.
   같은 강의의 가까운 프레임은 독립성이 낮다. 강의·시간 구간 단위로 분리한다.
2. **현재 자료 범위**: Git에는 V34와 비교 그림·결과·실데이터 URL이 있고,
   전체 원본 데이터셋/영상은 없다. 현재 확보한 실제 프레임 3장은 모두 화이트보드다.
   검은 칠판, 모션 블러, 의미 있는 교수자 가림, 연속 영상의 시간적 안정성은 미검증으로 남긴다.
3. **평가 기준 좌표**: 같은 해상도에서는 모든 방법에 동일 RGB/GT/ROI를 쓴다.
   해상도 간 비교에는 원본 1080p GT를 유지하고 저해상도 예측만 nearest로 투영한 지표도 기록한다.
   720p로 GT까지 줄인 지표는 별도 항목으로 분리한다. 두 지표를 섞어 과거 점수와 비교하지 않는다.
4. **파라미터의 공간적 크기**: window=25/radius=2를 1080p와 720p에 그대로 쓰면
   원본 장면에서의 물리적 범위가 달라진다. 픽셀 단위 고정 실험인지, 공간 범위를 맞춘 실험인지
   명시해야 한다. 현재 소규모 실험은 픽셀 고정 설정이며 B0의 해상도 효과와 구분한다.
5. **파라미터 선택과 최종 평가 분리**: 같은 프레임의 GT로 최고 설정을 고르고 그 점수를
   최종 성능으로 발표하면 낙관적인 결과가 된다. 현재 3장 결과는 탐색용이며,
   이후에는 강의별 개발/평가 분할을 먼저 고정한다. V34 학습 포함 여부도 미확인이다.
6. **OCR 보조 지표의 범위**: 획 보존/CC 개수/레이아웃 관찰은 OCR 정확도의 대체값이 아니다.
   설치된 Tesseract의 영문 CER은 수식 인식 정확도가 아니다. 모든 비교군에 같은 crop,
   engine/version/language/PSM/정규화 규칙을 사용하고 실제 예측 문자열을 남긴다.
7. **수식 의미 검사**: 분수선/점/위첨자/괄호 범위를 개별 crop의 확인 항목으로 기록한다.
   수식 OCR이 없다면 사람이 확인한 손상 사례로 보고하고 수식 EM을 만들지 않는다.
   향후 LaTeX 정규화는 공백/표현 규칙을 미리 고정하되 `-`/`=`, 위첨자와 본문 같은 의미 차이를 지우면 안 된다.
8. **자원 수치**: B0 복사 시간 0과 모델 추론 시간을 분리한다. peak RSS는 프로세스 누적
   최고치이므로 방법별 메모리라고 부르면 안 된다. 캐시 첫 실행과 재사용 실행도 구분한다.
9. **PDF와 시간적 안정성**: 한 프레임의 PDF 표시 확인은 실제 영상→ST3D→PDF 검증이 아니다.
   B3 추가 픽셀이 프레임마다 달라지면 CC 안정성/요약 결과에 영향이 있을 수 있다.
   정지 프레임 평가 다음에 짧은 실제 연속 구간을 별도 검증한다.

## 이번에 적용한 범위

- 원래 합성 결과/회귀 테스트를 보존한다.
- 고정한 실제 프레임 3장에 대해 native 1080p와 derived 720p를 비교한다.
- B0~B4 기존 후보를 실행하고, CLAHE on은 w25/k.2 한 가지 탐색 조건만 추가한다.
- 전체 영역/동일 board ROI, 원본 좌표의 수식·영문 crop, 변경 픽셀 표시를 저장한다.
- 이미 설치된 Tesseract로 손으로 전사한 영문 제목 3개만 보조 평가한다.
- 실제 수식 인식/Whisper/학습/추가 checkpoint/전체 영상 처리는 하지 않는다.
- 12~20장 확장 평가가 완료됐다고 주장하지 않는다.

## V2로 가져갈 권고

현재로서는 **원본 RGB + V34 B0 + 선택적 V1.5 후보를 함께 보존**하는 구성이 타당하다.
이는 특정 입력이 OCR에 더 좋다고 미리 확정한 것이 아니라, 아직 확인하지 못한 정보를
이진화 단계에서 버리지 않기 위한 선택이다. 후보 채택은 추가 표본과 downstream 평가로 결정한다.
