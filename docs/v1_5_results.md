## 실제 수행한 검증

- CPU 환경: Python 3.12.14, NumPy 1.26.4, OpenCV 4.10.0,
  Torch 2.5.1+cpu (정확한 환경 문자열은 각 metrics.json 참고). OpenCV/Torch 스레드 2.
- 단위/통합 테스트 7개 통과. 마지막 실행 약 3.16초.
  작은 이미지(1×1, 2×3 포함), 빈/단색 입력, 출력 크기/극성/재현성,
  B3 기존 픽셀 보존 및 확장 영역 제한, GT 없는 지표 생략, ROI/shape 검사,
  Torch 없는 후처리 import, 정지 이미지 CLI, cache miss→hit를 검증했다.
- 축소 채널의 기존 FCN 구조 + 고정 난수 가중치를 이용한 **추론 전용** 회귀 테스트:
  B0가 기존 `binarize(force_binary=True)`와 픽셀 단위 동일하고,
  영상 worker의 반전 출력과도 일치한다. B4의 판서 확률이
  `1-sigmoid(logits)`와 동일한지도 확인했다. 학습/역전파는 수행하지 않았다.
- `git diff --exit-code -- ACCESS2021_release DLHAU2020_release` 통과:
  기존 릴리스 파일 변경 없음. `git diff --check` 통과.
- 합성 정지 이미지 3장: 흰 칠판 1280×720 / 1920×1080, 밝은 글씨 칠판 1920×1080.
  글씨/수식(`+`, `=`, 괄호), 명도 기울기, 교수자를 흉내 낸 사각형/원을 포함한다.
  안티앨리어싱 없는 합성 글씨에서 GT를 정확히 생성했다.
- 합성 baseline은 GT에서 매 13번째 열의 글씨 픽셀을 제거한 **의도적 손상 fixture**다.
  **B0 이름은 CLI 경로의 기능 검증을 위한 것이며 LectureNet 결과가 아니다.**
- 합성 B0~B3 PNG 33개(장당 B0 1개, B1 2개, B2 4개, B3 4개),
  Contact Sheet 3개, 원본/GT/설정/metrics JSON을 저장했다.
  B4는 연속 모델 출력이 없어 이 데모에서 skip했다. B4 연산은 회귀/통합 테스트에서 실행했다.

## 합성 fixture 수치 — 실제 강의 성능 아님

모든 수치는 전체 프레임 GT로 계산했다. 표는 후보 중 B1 blur=0,
B2/B3 window=25, k=.2, CLAHE off, B3 radius=2를 발췌한 것이다.
다른 후보의 precision/recall/F1/IoU, CC 분포/전경 비율은 JSON에 있다.
시간은 단일 실행의 후처리 연산 시간으로 I/O/평가 제외, 반복 벤치마크가 아니다.

## 관찰과 해석

- 확대 Contact Sheet에서 fixture B0의 `+`, `=`, 괄호와 글씨에 인위적 단절이 보인다.
  B3는 이 fixture의 삭제된 픽셀을 모두 복원했다. GT에 가깝고 주위에 실제 글씨가 있는
  매우 유리한 시작 조건이다. F1=1을 실제 V34 성능의 예상값으로 사용하면 안 된다.
- B1은 짙은 교수자 모형을 대량 전경으로 검출했다. B2는 균일 내부보다 경계 위주의
  오검출이 남았고, 전체 영역 precision이 낮았다. 합성 장면에서 예상 위험을 확인한 것이다.
- B3의 전경 추가는 원본 마스크의 dilation 내부로 제한되며 기존 전경은 보존된다.
  이는 단위 테스트로 검증한 구조적 성질이지 오검출 제거 성능의 증명이 아니다.
- 획 붙음, 그림자, 흐린 글씨, 실제 교수자 옷/칠판 경계, 모델의 완전 누락 영역은
  실데이터에서 아직 검증하지 않았다. 완전 누락 영역 복원은 B3 설계상 보장하지 않는다.
- 실제 LectureNet보다 개선/악화됐다고 결론 낼 자료는 없다.
  CLAHE 옵션은 구현되어 있으나 저장된 데모에서는 off이며 품질 효용을 평가하지 않았다.

## 비교군 실행 상태

| 비교군 | 구현 상태 | 실제 V34/강의 실행 |
|---|---|---|
| B0 | 외부 PNG 재사용 + CPU 추론/해시 캐시, V1 동등성 테스트 통과 | 체크포인트/검증된 캐시 부재로 미실행 |
| B1 | Otsu blur 0/3 | 합성 3장 실행, 실제 강의 미실행 |
| B2 | Sauvola 25/51 × .2/.35, CLAHE 옵션 | 합성 3장 실행(off), 실제 강의 미실행 |
| B3 | 제한된 dilation+Sauvola, 기존 전경 보존 | 손상 합성 fixture 실행, 실제 모델 마스크 미실행 |
| B4 | 연속 판서 확률 threshold .35/.5/.65, 추론 재사용 | 합성 통합/FCN 회귀 테스트만; 데모는 명시적 skip |

## 다음 단계에 대한 결론

B3를 우선 실데이터 검증 대상으로 가져갈 근거는 **기존 픽셀 보존과 추가 영역 제한**,
그리고 제어된 단절 fixture에서의 동작 확인이다. 실제 품질 향상이라는 근거는 아직 없다.
기존 V34 마스크가 정확하지 않을 경우 노이즈를 키울 수 있으므로 실제 채택 결정은 보류한다.
B1/B2는 독립 기준선으로 유지하고, B4는 같은 forward 결과에서만 임계값을 비교한다.

실제 다음 실행에는 동일 시점의 720p/1080p RGB 프레임 3~5장,
검증된 V34 checkpoint+config 또는 정렬된 기존 PNG/연속 확률이 필요하다.
실제 GT가 없다면 F1은 생성하지 않고, ROI 내 수식/얇은 획과 ROI 밖 교수자 오검출을
Contact Sheet 및 전체 PNG로 확인한다. 픽셀 GT가 준비되면 같은 ROI에서 정량 평가한다.
명령은 [구현 문서](v1_5.md#실행)를 따른다.
