# V2.51 실험 설계와 재현

기준은 work의 V2.5 커밋 `b2321ef`다. 기존 코드/데이터/결과를 보존하고
새 실험은 `experiments/v251`, `docs/assets/v251`, `benchmark-output/v251`에 분리한다.
기본값0의 확장 crop 후보 옵션을 V2.5에 추가했으며 원래 예측을 대체하지 않는다.
신규 모델/학습/자동 GT 기반 모델 라우팅은 없다. 기본 파이프라인은 변경하지 않는다.

## 고정 실험 조건

입력129개와 조건을 `manifest.json` 및 SHA256으로 고정했다. 모델당93개는 새로 추론하고,
기존18 ROI × RGB/V34의36개는 동일 가중치의 V2.5 원문 예측을 명시적으로 재사용한다.
재사용 값과 새 추론을 evidence 필드로 구분한다. baseline의 순서나 점수로 조건을 고르지 않는다.
준비 중 blank-only control 생성 오류를 수정해 최초 실행을 중단했으며 예측을 열어보기 전에
수정된 manifest를 고정했다. 중단 로그는 `benchmark-output/v251-aborted-before-blank-control-fix`에 보존한다.

| 그룹 | 이미지 수 | 목적 |
|---|---:|---|
| 실제 RGB/V34 baseline | 36 | 기존18 수식, 기존 추론 재사용 |
| 인쇄 대응본 | 18 | V34 crop과 같은 canvas, aggregate ink 외접 영역에 맞춤 |
| 구조 통제식 | 24 | 팩토리얼/분수/벡터/행렬/다중 행/첨자/집합·자연어 |
| 실제 crop 민감도 | 34 | 5사례 × RGB/V34 × pad10/pad20/tight + 2사례 × RGB/V34 × scale2 |
| 인쇄 입력 형식 | 8 | 6사례 빈 canvas 확장, 2사례 흑백 반전 |
| 분할 행 | 9 | 실제 연립2행, 인쇄2행/3행, 행렬2행의 파괴적 진단 |

129개는 서로 독립된129개 수식이 아니라 실제18 ROI와 통제24식의 조건별 파생 입력이다.
별도의 파이프라인 통합 검증에서는 같은 순열 행렬 원본/확장2개를 추가 추론했다.

24개 통제식은 같은 TeX 폰트/180dpi를 사용한다. 더 복잡한 구조의 총 높이를 강제로 같게 하지 않는다.
실제 대응본은 canvas와 전체 잉크 footprint를 근사하지만 개별 글자/획 두께/행 간격을 완전히
일치시키지는 못한다. 인쇄/판서 차이만 분리한 완벽한 인과 실험으로 해석하지 않는다.
원정답에 없는 획을 손글씨 입력에 추가하지 않는다.

crop 확장10/20%는 **기존 bbox의 폭/높이에 대해 각 변마다** 적용하고 전체 이미지에서 자른다.
흰 테두리 삽입과 달리 인접 판서도 포함될 수 있다. tight는 gray<200의 외접 영역,
scale2는 cubic 2배 확대다. RGB 색조/배경에 따라 tight threshold가 다르게 작동할 수 있다.
GT나 모델 결과로 조건을 바꾸지 않고 모델별 모든 조건을 보고한다. 최적 조건만 합친 정확도는 만들지 않는다.

## 모델 내부 입력

설치된 PaddleX의 실제 `UniMERNetImgDecode/TestTransform/*ImageFormat`을 별도 probe에서 실행한다.
전경 crop → 비율 유지 resize/thumbnail → 중앙 padding → grayscale normalization → tensor formatting이다.
S/plus-S는384×384, L은768×768, UniMERNet은192×672 입력 설정을 사용한다.
내부 crop은 gray min/max 정규화 후<200을 전경으로 판단한다. 외부 tight의 절대 threshold와 다르다.
디코드 미리보기와 정규화된 tensor shape/hash를 기록한다. 빈 canvas가 제거되어 tensor가 같다면
그 조건은 모델에 같은 픽셀이 들어간 것이다. 반전은 자동으로 원래 극성으로 복구하지 않는다.
실행된 소스의 SHA256도 기록한다. 내부 처리를 대체하거나 가중치를 바꾸지 않는다.

## 평가

공백만 제거한 Strict EM, edit distance를 유지한다. 실패/빈 문자열도 전체 분모에 포함하고,
렌더링 실패는 별도로 센다. 추가 구조 진단은 수학 동치 판정기가 아니다.

- matrix/array의 행수·열수·cell 토큰을 기록하며 표현 wrapper 차이와 내용 손실을 구분한다.
- factorial 수, 위/아래첨자 lexical 위치, aligned 행 문자열, 벡터→분수 의심을 기록한다.
- 정답/예측을 같은 TeX 엔진으로 렌더링하고 tight-ink 정렬 IoU를 설명용 지표로 저장한다.
  자동 정답 임계값을 두지 않는다. 다른 의미인데 비슷해 보일 수 있다.
- 별도 시각 검토 기록은 검토한 입력과 렌더링을 명시한다. 독립 인간 판정자 합의로 표현하지 않는다.
- 분할은 고정 기하 행 crop 진단이다. matrix 행 분할은 실제 적용 불가로 표시한다.
  aligned 재결합은 명시적 구조를 알고 있는 진단이며 원본 전체 예측도 보존한다.

## 재현

공유된 고정 PNG로 추론만 재실행할 때는 기존4모델이 필요하다. 입력을 다시 생성할 때는
V2.5 원본 프레임도 필요하다. prepare_data/prepare_b0로 추가 프레임을 복원하며,
기존3프레임은 V1.5/V2 문서를 따른다. 이미 고정된 manifest는 덮어쓰지 않는다.

```bash
# 새 입력 세트 생성 시에만; 기존 manifest가 있으면 거부한다.
python -m experiments.v251.prepare
python -m experiments.v251.run --ocr-python /path/to/paddle-env/bin/python
# 모델별 재개 가능; 완료된 같은 manifest 예측 파일은 재사용한다.
/path/to/paddle-env/bin/python -m experiments.v251.preprocess_probe
python -m experiments.v251.report
python -m experiments.v251.pixel_audit
python -m experiments.v251.split_probe
python -m experiments.v251.review_sheets
python -m experiments.v251.manual_review
python -m experiments.v251.tables
python -m pytest -q
python -m experiments.v251.validate
```

`run`은 저장된 예측이 있으면 재사용한다. 새 추론을 재현할 때는 predictions 폴더를 별도로
백업한 뒤 새로운 `--output benchmark-output/v251-repeat`으로 실행해 원시 로그도 보존한다.
manual_review는 이번에 직접 확인한92개 결정을 직렬화하는 코드다. 다른 이미지나 다른 모델 출력에
재사용 가능한 자동 동치 판정기가 아니며, 재실험 출력이 달라졌다면 시각 검토를 다시 해야 한다.

### 선택적 context 후보

```bash
python -m boardnotes.v25 image frame.png --b0 aligned-v34.png \
  --regions reviewed-regions.json --output output/context-review \
  --ocr-python /path/to/paddle-env/bin/python --formula-model UniMERNet \
  --formula-context-margin 0.1
```

기존 bbox/예측과 확장 bbox/예측을 함께 저장한다. 확장 후보에는 source_parent_id와 검토 flag를
남기고 metadata.context_candidates에 margin/출처를 기록한다. 자동으로 정답을 선택하지 않는다.
실제 통합 검증2개 예측은 고정 진단 실험의 같은 두 crop/문자열과 일치했다.
기본 margin0이며 invalid/NaN/out-of-range 값은 실행 전에 거부한다.

V1 환경에 OpenCV/ReportLab/pypdf, 시스템 TeX/pdftoppm가 필요하며 Paddle은 기존 독립 환경이다.
실제 측정은 CPU threads2/MKLDNN off, 모델 순차 적재, RSS budget6000MiB,
모델별 timeout3600초다. 추론 요청에는 id/image만 있고 정답은 평가 프로세스에만 있다.
모델별 raw IPC/로그는 ignored benchmark-output에, 공유 예측/입력/평가는 docs/assets/v251에 둔다.
일부 입력 probe/보고서 렌더링은 추론과 병행했다. 시간은 해당 실행의 관측치이며
전용 CPU에서 공정하게 비교한 속도 벤치마크나 모델별 속도 순위의 근거가 아니다.
네 신경망의 가중치는 동시에 적재하지 않았다. RSS는 worker 자체 값이며 전체 작업 합산 메모리가 아니다.
